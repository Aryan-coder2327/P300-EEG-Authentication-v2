\## EEG Preprocessing Plots



This folder contains visualization results from the EEG preprocessing

pipeline applied to the BNCI Visual P300 dataset (Subject 1).



\### Included Plots

\- Raw EEG signal (single EEG channel)

\- Raw vs bandpass filtered EEG (0.1–30 Hz)

\- Averaged P300 event-related potential (ERP)



These plots validate correct signal preprocessing, stimulus-locked

epoch extraction, baseline correction, and P300 identification.

They are used as evidence of progress for Phase-2 review.
