MODEL TRANSPARENCY / 04

Explain a decision

Generate a local SHAP explanation for a chosen window. Inspect the channel × time attribution map, ranked channel contributions and the model's score relative to its threshold.

⌁

Explainability workspace

SHAP is computed on demand using the saved early-stopping CNN and the existing project explainer. First enrol an identity to enable the lab.

Interpretation boundarySHAP explains contributions to the CNN logit, not a calibrated probability. Channel attribution is not causal proof and must not be interpreted as a standalone neural biomarker.
