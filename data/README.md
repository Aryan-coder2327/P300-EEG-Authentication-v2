\## Dataset Information



This project uses the \*\*BNCI Visual P300 Speller dataset\*\*.



\### Dataset Source

BNCI Horizon 2020 EEG Database  

https://bnci-horizon-2020.eu/database/data-sets



\### Files Used

\- s1.mat to s10.mat (Visual P300 paradigm)



\### How to Use

1\. Download the dataset from the BNCI website

2\. Place the `.mat` files in the following directory:



data/raw/



Example:



data/raw/s1.mat  

data/raw/s2.mat  

...



\### Notes

\- Raw EEG data is \*\*not included\*\* in this repository

\- This avoids large file storage and respects dataset distribution practices

\- Please cite the original dataset if used in publications
